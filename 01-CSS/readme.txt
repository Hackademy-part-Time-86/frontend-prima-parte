
La viewport è la porzione di pagina HTML visualizzata dall'utente

Responsive design con approccio:
- mobile first le media query sono scritte con min-width 
- desktop first le media query sono scritte con max-width 



La proprietà position permette di modificare la posizione degli elementi HTML rispetto alla posizione che questi assumerebbero normalmente
La proprietà position può assumere i seguenti valori:
- static (default)
- relative permette di posizionare un elemento HTML rispetto alla posizione che l'elemento assumerebbe normalmente
- absolute permette di posizionare un elemento HTML rispetto alla posizione del primo elemento antenato (parent) che ha proprietà position ad un valore diverso da static
- fixed permette di posizionare un elemento HTML rispetto alla viewport
- sticky una via di mezzo tra relative e fixed

La proprietà position va sempre utilizzata in combinazione con le proprietà:
- top oppure bottom
- left oppure right
